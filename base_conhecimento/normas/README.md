# Normas — base estruturada

Resumos de referência das normas aplicáveis a **içamento de carga**, organizados
um arquivo por norma. Servem para **ancorar o agente** (são lidos e enviados como
contexto). São resumos de **escopo e pontos-chave em linguagem própria** — não
substituem o texto oficial.

> ⚠️ **Confirme sempre a redação e a edição vigente** no texto oficial antes do uso
> em treinamento/documento oficial. NRs: gov.br (Ministério do Trabalho e Emprego).
> Normas ABNT: catálogo ABNT (são protegidas/comercializadas — não versionamos os PDFs).

## Como expandir

- Edite o arquivo da norma para detalhar pontos relevantes (sempre confirmando a fonte).
- Mantenha o padrão das seções: **Identificação · Aplicação ao içamento · Pontos-chave ·
  O que abordar no treinamento · Normas relacionadas**.
- Para uma norma nova, crie um arquivo seguindo o mesmo modelo e cite-o aqui no índice.
